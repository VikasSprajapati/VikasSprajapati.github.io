How I work

From "can we connect this?" to numbers people trust

The same five steps whether it's a marketplace, an ad platform or a client's HR system.

01 / Understand
Requirements

Talk to the people who'll use it. Agree what "correct" means: which report they trust, which timezone, which definitions.

02 / Connect
Access & auth

Apps, scopes, OAuth and tokens stored encrypted. Every connection gets a test and plain-language error messages.

03 / Build
AI-assisted, human-reviewed

Claude Code speeds up the build. I set the architecture, review every change and test it.

04 / Validate
Reconcile

Counts, totals and record-level checks against the source, until the numbers match. Then automated checks keep them matching.

05 / Ship
Release & stabilise

Task branches, UAT, production. Then I watch real data, fix edge cases fast, and document what I learned.
