Commerce Optimizer: one trusted view of every store, with AI that proposes and people approve.

A multi-store analytics platform. It brings each Shopify store's sales, advertising (Google, Meta, Microsoft), web analytics (GA4, Search Console) and on-site behaviour (Microsoft Clarity) into one dashboard, explains what changed and why, and proposes fixes that a person approves before anything changes.

The problem

The team checked Shopify, three ad platforms and several analytics tools separately, and reconciled the numbers by hand. Nobody had one view they trusted.

What I built

A portfolio view across all stores, and a workspace for each one.

Overview
Portfolio dashboard

25 core KPIs (sales, orders, AOV, ad spend, ROAS, MER, conversion rate…) with trends, "what moved sales" and a store comparison table.

Analytics
Per-store deep dives

Sales with refunds, customers, channels, discount codes and fulfilment speed; ads by campaign; traffic with the GA4 funnel and Clarity frustration signals; inventory sell-through and stock at risk.

Advertising
One ads dashboard

Google Ads, Meta Ads and Microsoft Ads side by side, with campaign-level flags for spend without return.

Health
Ads health score

0–100 from five data-driven checks: broken conversion tracking, wasted search terms, budget-limited winning campaigns, Meta ad fatigue, and spend without sales.

Insights
Alerts with evidence

Sales and ROAS drops, refund spikes, unshipped orders, checkout abandonment and "page not found" traffic, each with the likely cause, money impact and next step.

Reporting
Weekly Business Review

A review page that exports as a PDF deck and an Excel workbook, plus branded PDF, Excel and CSV exports for any period or set of stores.

AI that proposes, people approve

The AI (Claude, with Gemini as fallback) can act on live ad accounts, which is exactly why it isn't allowed to act alone.

The AI proposes

Pause or enable campaigns, change budgets (capped at ±20%), add negative keywords, or create discount codes.

A person approves

Each action is shown exactly as it will run, and approved individually.

It's logged and reversible

Guardrails on every action, a full audit log, one-click undo, and the effect is measured afterwards.

Nothing touches an ad account or a store until a person approves it.

Engineering highlights

  • Resilient sync pipeline: background workers claim jobs with FOR UPDATE SKIP LOCKED; 180-day history through Shopify bulk operations, then incremental syncs
  • Late data handled: recent ad days are re-synced because conversions keep arriving after the click
  • Financial accuracy: two refund bases, one of which matches Shopify's reports to the cent; ratios computed from period totals, never averaged
  • Budgeting a tight API: Clarity allows 10 requests a day, so the app uses at most 8 and keeps raw responses so data can be rebuilt
  • Affordable, reliable AI: Zod-validated JSON outputs, prompt caching, reuse of identical analyses, per-request cost metering and a monthly budget cap
  • Security and privacy: platform tokens encrypted with AES-256-GCM, no shopper names, emails or addresses stored, company SSO
  • Plain-language connection health: when a source stops working, the store shows what happened, where to fix it, and the steps
  • Fast: TanStack Query caching makes revisited pages appear in about 0.3 s

Search Optimizer: an AI agent that fixes Shopify SEO, AEO and GEO issues, and proves each fix worked.

It audits every store with eight tools, scores them on one comparable scale, then uses an AI agent to fix the issues in the theme and the store's content. A fix only counts when the audit tool itself confirms it.

Used byThe SEO team and management

The problem

Fragmented audits

Results came from many separate tools, and their scores weren't comparable.

Manual fixing

Fixing meant uploading audit files to a chat AI and copying the edits into Shopify by hand.

No proof

Nobody could tell which fixes had actually worked.

What I built

Audit
Unified audits

SEOmator, PageSpeed (median of 3 runs), GEO readiness, AI citability, brand presence, rich results, a deep site crawl and Search Console, combined into Overall, SEO, AEO and GEO scores with adjustable weights.

Fix
AI fix agent

Claude or Gemini with tool use edits a copy of the theme (Shopify CLI) and the store's content (Admin API): products, pages, blog posts, SEO titles, alt text.

Trust
Safe by design

Preview, review the diff, publish, one-click rollback, and an automatic theme backup before every publish.

Scale
Fix across stores

A fix verified on one store is reused on the others running the same theme, so each further store costs less.

Control
Cost control

Spend limits per fix, cost estimates before every run, and skip or stop for single issues or batches mid-run.

Show
Visible progress

Before and after for every fix, "why did the score change?", an AI track record per issue type, and a celebration for each confirmed gain.

An agent that checks its own work

The agent doesn't get to declare victory. Every fix goes through a verification loop before it counts.

It sees the real page

It views the rendered pages on a live preview served by Shopify CLI.

It runs the audit's own rule

It executes the audit tool's exact check against its own changes.

It retries with evidence

Issues that still fail go back to it automatically, with what the tool reported.

"Fixed" only counts when the audit tool agrees.

The bigger win: finding out why fixes looked ineffective

Early on, only about 10% of issues were being confirmed. Root-cause analysis found four causes, and the redesign fixed all of them.

  • Scoring settings were changing mid-test, so I added like-for-like comparisons
  • The AI was working blind, so it now sees the rendered pages
  • Issues were routed to the wrong place, so theme and content fixes now happen in one run
  • Confirmation ran before Shopify updated, so the audit now waits for the store to settle

How I work

From "can we connect this?" to numbers people trust

The same five steps whether it's a marketplace, an ad platform or a client's HR system.

01 / Understand
Requirements

Talk to the people who'll use it. Agree what "correct" means: which report they trust, which timezone, which definitions.

02 / Connect
Access & auth

Apps, scopes, OAuth and tokens stored encrypted. Every connection gets a test and plain-language error messages.

03 / Build
AI-assisted, human-reviewed

Claude Code speeds up the build. I set the architecture, review every change and test it.

04 / Validate
Reconcile

Counts, totals and record-level checks against the source, until the numbers match. Then automated checks keep them matching.

05 / Ship
Release & stabilise

Task branches, UAT, production. Then I watch real data, fix edge cases fast, and document what I learned.
